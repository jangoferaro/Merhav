# קהל — הקהל שלך הוא צוות המכירות שלך

מערכת פשוטה למכירת כרטיסים שעוזרת לאומנים להגדיל קהל:
כל אחד מהקהל יכול להפוך ל**שגריר**. הוא מקבל קישור אישי, משתף עם חברים,
ומקבל אחוזים מכל כרטיס שנקנה דרכו.

## איך זה עובד

| מי | מה הוא עושה | איפה |
|---|---|---|
| **אומן/ית** | פותח/ת אירוע: מחיר, כמות כרטיסים ו**אחוז לשגריר** | `/` |
| | מקבל/ת קישור ניהול סודי: מכירות, טבלת שגרירים, חוב לכל שגריר, סריקת כרטיסים בכניסה | `/manage/<טוקן>` |
| **כל אחד מהקהל** | נכנס לדף האירוע ולוחץ "קבלו קישור אישי" | `/e/<אירוע>` |
| **שגריר** | מקבל קישור `?ref=קוד`, כפתור וואטסאפ עם הודעה מוכנה, ולוח שמראה כניסות, כרטיסים ורווח | `/agent/<טוקן>` |
| **חבר שקנה** | קונה דרך הקישור ומקבל קודי כרטיס, ומיד מוצע לו להפוך לשגריר בעצמו | `/order/<טוקן>` |

**לולאת הצמיחה:** כל קונה מקבל מיד הצעה להיות שגריר, כך שכל כרטיס שנמכר יכול להביא את הכרטיס הבא.

### חוקים
- **ייחוס:** כשנכנסים דרך קישור של שגריר נשמרת עוגייה ל-30 יום. אם אדם נכנס דרך כמה שגרירים, הקנייה נזקפת לאחרון שבהם.
- **עמלה:** האחוז שהאומן קבע (0–50%) מסכום ההזמנה, מעוגל כלפי מטה לאגורה.
- **שגריר שקונה לעצמו** (אותו טלפון או אימייל) לא מקבל עמלה על הקנייה שלו.
- **כניסות** נספרות פעם אחת לכל מבקר.
- **תשלום לשגרירים:** האומן משלם בעצמו (ביט, פייבוקס, העברה) ולוחץ "סימון ששולם".
- רמה אחת בלבד: שגריר מרוויח רק על מי שקנה ישירות דרכו. אין "רשת" של עמלות בשרשרת, וזה מכוון.
- אין סיסמאות: הגישה לכל לוח היא דרך קישור סודי ארוך. זה פשוט, אבל מי שמחזיק בקישור יכול לנהל.

## הרצה

צריך Node 22.13 ומעלה. אין תלויות, אין `npm install`. המערכת משתמשת רק ב-HTTP וב-SQLite המובנים ב-Node.

```bash
cd kahal
npm start          # http://localhost:3000
npm test           # 13 בדיקות, כולל זרימה מלאה דרך HTTP
```

משתני סביבה (לא חובה):
- `PORT`: ברירת מחדל 3000
- `KAHAL_DB`: נתיב לקובץ המסד (ברירת מחדל `data/kahal.db`)
- `PUBLIC_URL`: הכתובת הציבורית, למשל `https://kahal.example.com`, כדי שהקישורים לשיתוף יהיו נכונים מאחורי פרוקסי

## מבנה

```
src/db.js       סכמת SQLite (events, agents, clicks, orders, tickets)
src/logic.js    כל חוקי העסק: אירוע, שגריר, קנייה + ייחוס + עמלה, תשלום, סריקה
src/views.js    דפי HTML בעברית (RTL), עם escape אוטומטי לכל קלט
src/server.js   ניתוב HTTP בלבד
public/style.css
test/           בדיקות node:test
```

## ⚠️ לפני שעולים לאוויר עם כסף אמיתי
1. **סליקה:** התשלום כרגע **מדומה**. כל הזמנה נרשמת כמשולמת. צריך לחבר ספק סליקה
   (Stripe, Grow/Meshulam, Cardcom, PayPlus): ליצור את ההזמנה רק אחרי אישור תשלום מה-webhook.
   המקום לעשות את זה הוא `purchase()` ב-`src/logic.js`.
2. **שליחת הכרטיס** במייל או ב-SMS. כרגע הקונה מקבל דף עם הקודים וצריך לשמור אותו.
3. **גיבוי** לקובץ ה-SQLite.
4. **צד משפטי ומס:** תשלום עמלות לאנשים פרטיים עשוי לחייב דיווח. כדאי לבדוק עם רואה חשבון.

## רעיונות להמשך
- שגריר אחד לכל האירועים של אומן (היום שגריר הוא לכל אירוע בנפרד)
- פרס לשגריר המוביל (כרטיס חינם, מפגש עם האומן) בנוסף לאחוזים
- ייצוא רשימת הקונים לאומן, כדי שהקהל החדש יישאר שלו
