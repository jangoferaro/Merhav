# סטודיו פונטים — יצירת פונט עברי מקורי

כלי שמייצר **פונט עברי מקורי** מתוך פרמטרים שאתם קובעים, עם תצוגה חיה בדפדפן.
הפונט שנוצר הוא שלכם, ואפשר להשתמש בו באתרים ובאפליקציות בלי לשלם רישיון.

## הרצה

צריך Python 3.10 ומעלה.

```bash
cd font-studio
pip install -r requirements.txt
python server.py
```

אחר כך פותחים בדפדפן: http://localhost:8000

## מה אפשר לעשות באתר

- **השראה:** נותנים לכלי פונט שאהבתם, באחת משלוש דרכים:
  - **תמונה:** צילום או צילום מסך של אותיות. כותבים מה כתוב בתמונה (ברירת המחדל היא כל האלפבית לפי הסדר), והכלי מזהה כל אות ומודד אותה. על התמונה מסומנות האותיות שזוהו.
  - **קישור:** עמוד של פונט ב-Google Fonts, קישור ישיר לקובץ פונט, אתר שמשתמש בפונט, או קישור לתמונה.
  - **קובץ פונט:** TTF, OTF, WOFF או WOFF2.

  הכלי **מודד** את הסגנון: עובי, ניגודיות, רוחב, עיגול פינות, נטייה, ריווח ופרופורציות. אחר כך הוא מכוון את הסליידרים. האותיות עצמן נבנות מהשלד של הכלי ולא מועתקות מהמקור, ולכן התוצאה מקורית. אחרי המדידה בוחרים וריאציה כדי להתרחק מהמקור, וממשיכים לכוונן ידנית. שום דבר לא נשמר בשרת. אל תתנו לפונט שלכם את השם של פונט ההשראה.
- **עריכת פונט קיים:** מעלים קובץ פונט או מדביקים קישור (למשל עמוד ב-Google Fonts) ומשנים את הפונט עצמו:
  - **שינויים בקווים:** עובי, ניגודיות (קווים אופקיים מול אנכיים), עיגול פינות, ואפקט קו מתאר (אותיות חלולות).
  - **שינויים בגודל ובמרווחים:** רוחב, גובה, נטייה, ריווח בין אותיות ורווח בין שורות.
  - **פונט משתנה:** אפשר לבחור ממנו גם את משקל הבסיס.
  - **שמירה על עובי:** בשינוי רוחב או גובה, הכלי יכול לשמור על עובי הקווים המקורי.
  - **ניקוד ו-kerning:** זזים יחד עם האותיות. הכלי תומך בפונטים מסוג TrueType ו-CFF/OTF.
  - **רישיון:** הכלי קורא את הרישיון מתוך הקובץ. פונט חופשי (OFL, Apache וכו') מותר לשנות, בתנאי שנותנים לו שם חדש והוא נשאר תחת אותו רישיון. אם לא נמצא רישיון חופשי, צריך לאשר לפני ההורדה שיש לכם זכות לשנות את הפונט. פונטים בתשלום בדרך כלל אוסרים שינוי.
- **סגנונות מוכנים:** נקודת התחלה בלחיצה אחת (גאומטרי, רך ועגול, צר וגבוה, קלאסי ועוד).
- **סליידרים:** גובה, רוחב, ניגודיות (עובי הקווים האופקיים מול האנכיים), עיגול פינות, נטייה, ריווח, אורך הראש של ו׳/י׳/נ׳, הזנב של ל׳ והעומק של האותיות הסופיות.
- **משקל:** הפונט הוא Variable Font, כלומר קובץ אחד שמכיל את כל המשקלים מ-100 (דק מאוד) עד 900 (שמן מאוד).
- **השוואה לרפרנס:** מעלים תמונה של אותיות שאוהבים (סקיצה, כתב יד, צילום), כותבים מעליה את אותן האותיות ומכוונים את הפרמטרים עד שהצורה קרובה. התמונה לא יוצאת מהדפדפן.
- **שמירת הגדרות:** קובץ `params.json` שאפשר לטעון שוב ולהמשיך לעבוד.
- **הורדה:** קובץ ZIP עם:
  - `variable/*.ttf` — הפונט המשתנה, להתקנה במחשב או לאפליקציות (iOS / Android / React Native).
  - `web/*.woff2` + `web/font.css` — לאתרים, מוכן להעתקה.
  - `static/*.ttf` — 9 משקלים קבועים, לתוכנות שלא תומכות בפונט משתנה.

## שימוש בפונט באתר (למשל באפליקציית מרחב)

מעתיקים את תיקיית `web/` לפרויקט ומוסיפים:

```html
<link rel="stylesheet" href="/fonts/font.css">
<style> body { font-family: "Otiyot", system-ui, sans-serif; } </style>
```

## איך זה עובד (למי שרוצה להבין)

| קובץ | תפקיד |
|---|---|
| `engine/glyphs.py` | ה"שלד" של כל אות: קווי מרכז ופינות. פה מעצבים את האותיות עצמן. |
| `engine/geometry.py` | הופך שלד לקו מתאר: עובי לפי כיוון (אופקי/אנכי), פינות מעוגלות. |
| `engine/analyze.py` | מודד סגנון של פונט ומתרגם אותו לפרמטרים. |
| `engine/image_analyze.py` | מזהה אותיות בתמונה ומודד אותן באותה שיטה. |
| `engine/fetch.py` | מוריד השראה מקישור, בצורה מאובטחת (בלי גישה לכתובות פנימיות). |
| `engine/edit.py` | עריכת פונט קיים: עיבוי (בשיטת FreeType), שינוי קנה מידה, פינות, ניקוד ורישיון. |
| `engine/build.py` | בונה שלושה "מאסטרים" (דק, רגיל, שמן), מחבר אותם לפונט משתנה, ומייצא קבצים. |
| `server.py` | שרת קטן שמגיש את האתר ובונה את הפונט לפי בקשה. |
| `static/` | האתר עצמו. |
| `tests/` | בדיקות שמוודאות שכל צירוף פרמטרים בונה פונט תקין. |

הרצת הבדיקות: `python -m unittest discover tests`

## מגבלות נוכחיות (ומה אפשר להוסיף בהמשך)

- כרגע יש את 27 האותיות וסימני פיסוק בסיסיים. אין עדיין **ניקוד**, **ספרות** ו**אותיות לטיניות**. במקומם הדפדפן משתמש בפונט גיבוי.
- הרפרנס משמש להשוואה ויזואלית. המרה אוטומטית של כתב יד לפונט היא שלב הבא אפשרי.
- אין עדיין kerning (התאמת מרווח בין זוגות אותיות ספציפיים). בעברית זה פחות קריטי מאשר באנגלית.
