# JoCares Door

אפליקציית הכניסה לצוותי דלת של מקומות, ליינים ואמנים. iOS ו-Android, ב-Expo (React Native).
העיצוב: הקנבס "JoCares Door" (7 מסכים). השרת: `encore/`, נתיבי `/door/app/v1/*`.

## מה יש בה
- **הצטרפות:** סורקים את ה-QR של הקישור האישי מהמארגן (במסך "צוות כניסה" באתר), או מדביקים את הקישור. בלי סיסמה. המפתח נשמר בכספת של המכשיר (Keychain / Keystore).
- **ההופעות:** של המארגן, מאתמול ועד שבוע קדימה, עם כמה נכנסו מתוך כמה.
- **סריקה רציפה:** במצלמה של המכשיר. התוצאה מוצגת גדול: ירוק-ליים לכניסה, אדום לדחייה. יש צליל (גם על שקט) ורטט. המסך לא נכבה.
- **ביטול כניסה:** עד 5 דקות אחרי הסריקה.
- **בלי קליטה:** בדיקה מול רשימה שמורה, שבה רק גיבוב של כל קוד. הכניסות נשמרות בתור ונשלחות כשהקליטה חוזרת. התנגשויות מוצגות.
- **אורח בלי טלפון:** חיפוש לפי שם, שם המזמין או סוף הקוד.
- **מצב הדלת:** בפנים מתוך הכל, 15 הדקות האחרונות, וכניסות לפי איש צוות.

## הרצה על המק
```bash
cd apps/door
npm install
npx expo run:ios            # בונה ומריץ בסימולטור (צריך Xcode)
npx expo run:ios --device   # על אייפון מחובר
```
בסימולטור אין מצלמה. בודקים הצטרפות עם "הדבקת קישור" ובדיקת כרטיס עם "הקלדת קוד". סריקה אמיתית בודקים על מכשיר.

קישור צוות לבדיקה: באתר (staging), ב"צוות כניסה", מוסיפים איש צוות ומעתיקים את הקישור.

## העלאה ל-App Store
```bash
npx eas-cli@latest login
npm run build:ios      # בנייה בענן של Expo, עם חתימה אוטומטית מחשבון ה-Apple Developer
npm run submit:ios     # שליחה ל-App Store Connect / TestFlight
```
או דרך Xcode: `npx expo prebuild -p ios`, פותחים את `ios/JoCaresDoor.xcworkspace`, ואז Product > Archive.

- Bundle ID: `com.jocares.door`
- שם בחנות: JoCares Door
- הרשאה: מצלמה בלבד. בלי מיקום, בלי מיקרופון, בלי מעקב.
- הצפנה: `ITSAppUsesNonExemptEncryption=false` (רק HTTPS רגיל).
- לבודקי Apple: צריך קישור צוות פעיל להופעה לדוגמה ב-staging. מכינים אותו לפני ההגשה ומדביקים ב-Review Notes.

## בדיקות לפני שחרור
```bash
npm run typecheck
npx expo export --platform ios   # שהבנדל נבנה
```
בצד השרת: `cd encore && npm test`. הבדיקה "API לאפליקציית הנייטיב" מכסה הזדהות, סריקה, חיפוש, סנכרון, ביטול וביטול גישה.

## הערות
- הניווט פשוט, במצב פנימי ולא ב-Expo Router: חמישה מסכים, זרימה אחת. אם האפליקציה תגדל (קונים, ג׳וקרים), עוברים ל-Expo Router.
- הכיוון מימין לשמאל נקבע במפורש במסכים, כך שהתצוגה זהה בכל שפת מכשיר.
