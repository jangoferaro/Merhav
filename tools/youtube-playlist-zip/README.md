# פלייליסט יוטיוב ← קובץ ZIP

כלי קטן: מדביקים קישור לפלייליסט ביוטיוב, ומקבלים את כל הסרטונים שבו בקובצי
ZIP של עד 30MB כל אחד, ממוספרים לפי הסדר בפלייליסט (`001 - שם הסרטון.mp4`
וכן הלאה).

## התקנה (פעם אחת)
1. להתקין [Python 3](https://www.python.org/downloads/). ב-Windows לסמן את
   האפשרות "Add Python to PATH".
2. מומלץ: להתקין גם [ffmpeg](https://ffmpeg.org/download.html). בלעדיו
   האיכות מוגבלת בדרך כלל ל-720p, אי אפשר להמיר ל-MP3, וסרטונים ארוכים לא
   נחתכים לחלקים שאפשר לצפות בהם (ראו בהמשך).
   - Windows: `winget install ffmpeg`
   - Mac: `brew install ffmpeg`
3. בתיקייה הזו להריץ:
   ```bash
   pip install -r requirements.txt
   ```

## שימוש
```bash
python playlist_to_zip.py
```
הכלי יבקש להדביק את הקישור לפלייליסט. אפשר גם להעביר את הקישור ישירות:

```bash
python playlist_to_zip.py "https://www.youtube.com/playlist?list=..."
```

אפשרויות:
| אפשרות | מה היא עושה |
|---|---|
| `--audio` | מוריד רק אודיו (MP3) |
| `--max-height 720` | מגביל את האיכות (למשל 480, 720, 1080) כדי לחסוך מקום |
| `--max-size 25` | גודל מקסימלי לכל ZIP ב-MB (ברירת המחדל: 30). `0` יוצר ZIP אחד בלי הגבלה |
| `-o תיקייה` | איפה לשמור את ה-ZIP (ברירת המחדל: התיקייה הנוכחית) |

## חלוקה לקבצים של עד 30MB
- אם הכול נכנס ב-30MB, נוצר ZIP אחד על שם הפלייליסט. אחרת נוצרת תיקייה על
  שם הפלייליסט, ובה הקבצים `part 01 of 05.zip`, `part 02 of 05.zip` וכן הלאה.
- כל ZIP הוא קובץ עצמאי שאפשר לפתוח לבד, בלי צורך בשאר החלקים.
- סרטון שגדול מ-30MB נחתך לכמה סרטונים קצרים יותר
  (`... - part 1 of 3.mp4` וכן הלאה), ואפשר לצפות בכל אחד מהם בנפרד. בשביל זה
  צריך ffmpeg.
- בלי ffmpeg, סרטון גדול מחולק לחלקים גולמיים (`.001`, `.002`...) שצריך
  לחבר מחדש לפני הצפייה. בסוף הריצה הכלי מדפיס בדיוק איזו פקודה להריץ.

## טוב לדעת
- סרטונים פרטיים, מחוקים או חסומים מדולגים,
  ובסוף מופיעה הודעה שמציינת כמה סרטונים דולגו.
- בזמן ההורדה הסרטונים נשמרים בתיקייה זמנית ליד ה-ZIP, ונמחקים בסוף, כך
  שצריך פנוי בערך פי שניים מגודל הפלייליסט.
- אם ההורדה פתאום מפסיקה לעבוד, בדרך כלל יוטיוב שינה משהו. עדכון פותר את זה:
  `pip install -U yt-dlp`
- שימו לב לזכויות יוצרים ולתנאי השימוש של יוטיוב. מותר להוריד תוכן שלכם,
  תוכן ברישיון חופשי או תוכן שקיבלתם רשות להוריד.
